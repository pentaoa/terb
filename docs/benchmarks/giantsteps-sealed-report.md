# GiantSteps 封存子集三方 BPM 基准

20 首官方 MD5 校验的 Beatport preview；10 个常见流派各 2 首，ID 在模型、112 帧窗口和解码参数冻结后选定。误差容忍为 ±4%。原始与派生音频不随仓库分发。
